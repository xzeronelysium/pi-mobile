# Support

- **Questions and usage help:** open an issue with the `question` label. Include the app version, Android version, and a concise description; remove credentials and personal workspace data. (GitHub Discussions are not currently enabled for this repository.)
- **Reproducible bugs:** open a GitHub issue with steps to reproduce, expected and actual behavior, and sanitized logs/screenshots.
- **Security reports:** do not use public issues. Follow [SECURITY.md](SECURITY.md) and report privately through GitHub's Security tab.
- **Feature ideas:** open an issue describing the problem and intended user outcome before proposing a large change.

This is an actively developed project maintained on a best-effort basis; support response times are not guaranteed.
